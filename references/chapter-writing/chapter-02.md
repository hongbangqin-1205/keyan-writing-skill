# 第二章 项目建设背景和必要性（章节总纲）

本章回答"**为什么要建这个项目**"，从政策背景、规划符合性、建设必要性、建设可行性四方面论证项目立项的正当性。
本章是**论证章**，与第一章（陈述章）不同：每段都要有"**依据 → 分析 → 落到本项目 → 明确结论**"的论证链，
不列清单、不铺表格，而是讲清"为什么"。

## 写作流程

每节均执行同一流程，没有小节大纲不得进入正文起草：

```text
素材卡 → 小节正文大纲 → 第一轮写全写足 → 第二轮查漏补缺 → 校验
```

## 章节通用纪律

- **论证范式**：每段"依据（政策文号/现状数据，有锚点）→ 分析 → 落到本项目 → 明确结论"；
  不空喊口号、不堆砌政策名，政策引用后必须落到"本项目如何响应"。
- **证据**：政策文件名、文号、发文时间、现状数字必须来自证据；政策文号、标准版本、法规施行日期必查知识库（KB- 卡为主）；
  现状数据来自本地调研报告（SRC），不得编造。
- **锚点**：事实句 `〔SRC-007〕`/`〔KB-001〕`/`〔WEB-001〕`，分析推导句 `〔推导：依据〕`；发布时由 assemble 剥离。
- **文风**：正式书面语、客观中性；"依据→分析→结论"逻辑清晰；不写手工章节编号。
- **两轮**：第一轮写全写足、达到 profile `item_depth` 逐项下限；第二轮只查漏补缺，并记录到 `丰富记录.md`。
