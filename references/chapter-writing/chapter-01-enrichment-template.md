# 第一章正文查漏补缺记录模板

`丰富记录.md` 记录第二轮对第一轮正文的查漏补缺：检查、检索、补写和取舍。
第一轮已写全写足，第二轮只补缺口，不做"补厚"。

## 模板

```markdown
# 丰富记录 · chapter_01

## 第一轮正文检查

### 已覆盖
- 列出已经写入正文并达到 item_depth 下限的必写要素

### 发现缺口
- 小节/要素：缺口表现
- 影响：政策文号/标准版本/法规日期缺失、明细表未下钻、职能截断、绩效框架不符、证据不足等

## 第二轮查漏补缺

### 本地原文检索（extracted/ 全量文本）
- 查询：
- 新增来源：SRC-xxx
- 采用内容：

### 知识库检索
- 知识库：
- 查询问题：
- 新增来源：KB-xxx
- 采用内容：
- 未采用结果及原因：

### 网络检索
- URL：
- 检索日期：
- 新增来源：WEB-xxx
- 采用内容：

### 技术推导
- 推导内容：
- 依据：
- 适用前提和边界：

## 第二轮修订

- 补充了哪些事实、政策、技术、指标或表格：
- 调整了哪些段落逻辑：
- 删除或保留哪些内容及原因：
- 是否仍有 GAP：

## 完成判断

- 内容覆盖：通过/待补
- item_depth 逐项下限：通过/待补
- 绩效目标标准框架（成本/产出/效益/满意度）：通过/待补
- 明细表下钻到系统级：通过/待补
- 证据支撑：通过/待补
- 逻辑与章节衔接：通过/待补
```

## 第二轮必查清单（逐项打勾）

- [ ] 建设目标要素齐全（全生命周期、服务对象、五方向、六类应用、预期效果）
- [ ] 建设内容、建设模式下钻到系统级（明细表含功能模块列）
- [ ] 绩效目标用成本/产出/效益/满意度四类一级指标框架
- [ ] 编制依据下钻到系统级、三要素齐全
- [ ] 标准规范行业/技术两小类分列、编号齐全
- [ ] 建设单位职能完整（含职责分工），无截断
- [ ] 法规施行日期、标准版本已从 KB 补齐或显式 GAP
- [ ] 投资构成表与事实基线一致
